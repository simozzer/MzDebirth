An ambient demo: the sea and whales, something to fall asleep to. And the Mz950's new disks.

## Downloads

- **MzDebirth-0.14.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's fifteen sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.14.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.14.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.14.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.14.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.
- **mzdebirth_0.14.0_arm64.deb** - Raspberry Pi 5 (beta), on 64-bit Raspberry Pi OS Bookworm or
  later: installs MzDebirth in the menu, under Sound & Video.
- **MzDebirth-0.14.0-linux-arm64-beta.tar.gz** - the same for any 64-bit ARM distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.14.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

**Raspberry Pi 5:** install the arm64 .deb the same way,

    sudo apt install ./mzdebirth_0.14.0_arm64.deb

and choose the "default" or "pipewire" output under Options. A Pi is much slower than a
desktop PC, so if the sound crackles, raise the buffer size there. It's built natively on
GitHub's ARM machines, passes the same checks as the others, and has been played on a Pi 5.
A Pi 4 on 64-bit Raspberry Pi OS may run it too, if more slowly; a 32-bit system won't.

## What's new

- **An ambient demo.** **NEW** now offers two demo songs: the **acid demo**, the rave tune a
  new rack opens with, and the **ambient demo**, something to fall asleep to. The ambient
  demo is 64 bars at 72 bpm in E flat, about three and a half minutes, with no drums:
  - the **Mz950** loads its new `WHALES` disk on the `WHALE SEA` programme. It holds the
    sea the whole way through, and whale calls drift in over it: humpbacks, a blue whale, a
    minke and an orca, all public-domain recordings;
  - the **Mz7** plays slow chords on `WARM PAD`;
  - the **101** plays a slow melody through a long echo;
  - the **303** plays a soft low pulse, its filter breathing open and shut.

  At the end the sea fades away. The factory grooves are in the banks as usual, except the
  Mz950's, which need the drum disk.
- **The Mz950's new disks**, from [Mz950 0.12.1](https://github.com/simozzer/Mz950/releases/tag/v0.12.1):
  - `BIRDS` is now real birdsong, recorded;
  - `OCEAN` is the sea, from under the water, looped;
  - `WHALES` is eight whale calls, all public domain.

  That makes fifteen disks.

**On the Mac**, `install.sh` never copies a disk over one of the same name, so that your edits
survive an update. If you installed 0.13.0 or earlier, your `BIRDS.hfe` is still the old drawn
one. Delete it from `~/Library/Application Support/MzDebirth/Disks` before running
`install.sh` to get the recorded birds.

Racks saved before open as they were. Everything else is as in [0.13.0](https://github.com/simozzer/MzDebirth/releases/tag/v0.13.0).
