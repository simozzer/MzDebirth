A choir for the Mz950: the sample library's eighth disk.

## Downloads

- **MzDebirth-0.11.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's eight sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.11.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.11.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.11.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.11.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.11.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

## What's new

- **A choir.** The Mz950 comes with an eighth disk, `CHOIR`: a section singing "ooh" and
  "aah" from A1 to G4, eight voices to a note, each a little off the others with a vibrato
  of its own, and some air on the "aah". **LOAD DISK** on the Mz950, then pick a programme -
  `VOICE OOHS`, `VOICE AAHS`, `CHOIR` for both at once, or `DARK OOHS` to sit further back.
  The samples loop seamlessly, so a note holds as long as the key does, and swell in on the
  sampler's envelope. Like the rest of the library it is drawn rather than recorded, so it
  carries nobody's voice. The other seven disks are unchanged.

Everything else is as in [0.10.1](https://github.com/simozzer/MzDebirth/releases/tag/v0.10.1).
