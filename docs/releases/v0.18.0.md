## Downloads

- **MzDebirth-0.18.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's fifteen sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.18.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.18.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.18.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.18.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.
- **mzdebirth_0.18.0_arm64.deb** - Raspberry Pi 5 (beta), on 64-bit Raspberry Pi OS Bookworm or
  later: installs MzDebirth in the menu, under Sound & Video.
- **MzDebirth-0.18.0-linux-arm64-beta.tar.gz** - the same for any 64-bit ARM distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.18.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

**Raspberry Pi 5:** install the arm64 .deb the same way,

    sudo apt install ./mzdebirth_0.18.0_arm64.deb

and it plays through the Pi's HDMI output from the first run, with no USB sound card needed;
to use something else, pick it under Options. A Pi is much slower than a desktop PC, so if the
sound crackles, raise the buffer size there. It's built natively on
GitHub's ARM machines, passes the same checks as the others, and has been played on a Pi 5.
A Pi 4 on 64-bit Raspberry Pi OS may run it too, if more slowly; a 32-bit system won't.

## What's new

- **The DIST is ReBirth's own.** It's ReBirth's distortion, ported to C++ from
  [OpenRB-338](https://github.com/pingw33n/openrb-338)'s decoding of it: its curves, its gains,
  and its timing, the knobs answering as slowly as ReBirth's did.
  - **AMOUNT and SHAPE** read 0 to 127, as ReBirth's, and start at 70 and 0.
  - **SHAPE 0** is ReBirth 1.5's hard clip. Up from there, the curve goes ever further round
    ReBirth's waveshaper, from a warm bend to a folding fuzz.
  - **No make-up gain:** as in ReBirth, it gets louder the harder it's driven.
- **The same as MzPCD's.** The DIST is compiled from [MzPCD](https://github.com/simozzer/MzPCD)'s
  repository, so MzPCD 0.4.0, the pattern-controlled distortion plugin, distorts just the same.
- **The factory rack's DIST** is at ReBirth's 70, which keeps the mix about as it was: the kick
  a touch fuller, and the whole a little louder into LIMIT.

**Racks saved before** open with their DIST knobs where they were, which now mean ReBirth's
AMOUNT and SHAPE, so they sound different. For ReBirth's own starting point, set AMOUNT to 70
and SHAPE to 0.

Everything else is as in [0.17.0](https://github.com/simozzer/MzDebirth/releases/tag/v0.17.0).
