A seventh machine: the Mz106, a Juno-106. Its arpeggios in both demo songs, and drum machines whose knobs fold away.

## Downloads

- **MzDebirth-0.15.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's fifteen sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.15.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.15.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.15.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.15.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.
- **mzdebirth_0.15.0_arm64.deb** - Raspberry Pi 5 (beta), on 64-bit Raspberry Pi OS Bookworm or
  later: installs MzDebirth in the menu, under Sound & Video.
- **MzDebirth-0.15.0-linux-arm64-beta.tar.gz** - the same for any 64-bit ARM distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.15.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

**Raspberry Pi 5:** install the arm64 .deb the same way,

    sudo apt install ./mzdebirth_0.15.0_arm64.deb

and choose the "default" or "pipewire" output under Options. A Pi is much slower than a
desktop PC, so if the sound crackles, raise the buffer size there. It's built natively on
GitHub's ARM machines, passes the same checks as the others, and has been played on a Pi 5.
A Pi 4 on 64-bit Raspberry Pi OS may run it too, if more slowly; a 32-bit system won't.

## What's new

- **The Mz106.** A Juno-106 joins the rack, under the Mz7, from the
  [Mz106](https://github.com/simozzer/Mz106) plugin.
  - **Patches:** pick one of the 128 it comes with, numbered as a 106 numbers them, A11 to
    B88. Or use **LOAD .SYX** for Juno-106 patches, a whole bank or a single patch.
  - **Knobs:** **FREQ**, **RES**, **ENV**, **A** and **R** move the patch's own sliders.
    **CHORUS** overrides the patch's chorus. **VOLUME** is the plugin's: turn it up for a
    single-note line, and leave it down for chords. They're all automatable in a song.
  - **Stereo:** its chorus has a stereo channel on the mixer, and it hisses as a real one
    does.
  - **Patterns:** its steps are a grid of notes like the Mz7's. A 106 has no velocity, so
    accents play as any other note. **GENERATE** writes it an arpeggio of the chords, and
    **TRANSPOSE** moves it with everything else. Copy and paste work as they do for the Mz7.
- **The demos.**
  - **Acid demo:** the Mz106 arpeggiates the chords on `ARP PULSE` through both drops and the
    breakdown, its filter opening into the second drop.
  - **Ambient demo:** a soft, echoing arpeggio on `SEQ PLUCK` drifts in from bar 13, its
    filter sweeping slowly open and shut, and fades out before the last chord.
  - **No clicks:** the ambient demo is free of the clicks it had. They came from crackle in
    some of the whale recordings, which [Mz950 0.12.2](https://github.com/simozzer/Mz950/releases/tag/v0.12.2)
    cleans up. The demo also leaves out the sperm whale and minke calls, which are trains of
    clicks by nature, and softens the Mz950 a little.
- **Drum machine knobs fold away.** The Mz808 and Mz909 have a **SOUND** bar over their
  knobs. Click it and the knobs fold away, leaving the instrument select and the step keys,
  which are what you go back to once the sounds are set. The rack remembers it.

Racks saved before open as they were, with the Mz106's patterns empty until you write or
generate some. Everything else is as in [0.14.0](https://github.com/simozzer/MzDebirth/releases/tag/v0.14.0).
