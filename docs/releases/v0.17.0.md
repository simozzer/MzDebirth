Play the rack from a MIDI keyboard - and, on Windows, ASIO, for a keyboard that feels tight.

## Downloads

- **MzDebirth-0.17.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's fifteen sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.17.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.17.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.17.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.17.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.
- **mzdebirth_0.17.0_arm64.deb** - Raspberry Pi 5 (beta), on 64-bit Raspberry Pi OS Bookworm or
  later: installs MzDebirth in the menu, under Sound & Video.
- **MzDebirth-0.17.0-linux-arm64-beta.tar.gz** - the same for any 64-bit ARM distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.17.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

**Raspberry Pi 5:** install the arm64 .deb the same way,

    sudo apt install ./mzdebirth_0.17.0_arm64.deb

and it plays through the Pi's HDMI output from the first run, with no USB sound card needed;
to use something else, pick it under Options. A Pi is much slower than a desktop PC, so if the
sound crackles, raise the buffer size there. It's built natively on
GitHub's ARM machines, passes the same checks as the others, and has been played on a Pi 5.
A Pi 4 on 64-bit Raspberry Pi OS may run it too, if more slowly; a 32-bit system won't.

## What's new

- **Play a machine from a MIDI keyboard.** Plug in a keyboard and tick it under **Options**,
  *Audio/MIDI Settings*. Then click a machine's name plate, at the top of its mixer strip: it
  lights green, and the keyboard plays that machine, over whatever the patterns or the song are
  playing. Click another plate to move it, or the lit one to turn it off. Each note lands on the
  sample it arrives on.
  - **Mz303 and Mz101** play the last key held. Playing legato slides from note to note, and
    letting go of a key falls back to the one still held. Velocity 100 or more is an accent.
  - **Mz808 and Mz909** play their instruments by the General MIDI drum map: C1 is the bass
    drum, D1 the snare.
  - **Mz950, Mz7 and Mz106** play chords, with pitch bend. The mod wheel turns the Mz7's MOD
    knob and the Mz106's mod lever, and moves the Mz950's wheel. A sustain pedal holds the
    Mz7's notes and works the Mz106's HOLD.

  The machine the keyboard plays is saved with the rack. Moving it isn't a change that asks to
  be saved.
- **ASIO on Windows, for less latency.** *Windows Audio* holds to about ten milliseconds
  whatever buffer is asked for, and with the time a note waits for the next buffer, a keyboard
  can feel slow. An audio interface's own ASIO driver gets that down to a few milliseconds: in
  *Audio/MIDI Settings*, pick **ASIO**, then its driver, at 64 to 256 samples.
- **A shorter buffer on a first run.** On Windows the first run opens *Windows Audio (Low
  Latency Mode)*, still shared with other programs, and on a Mac and Windows it picks the
  buffer nearest 256 samples the device offers. Many built-in sound chips go well under ten
  milliseconds this way; some interfaces' Windows drivers don't, and those want ASIO. An audio
  setup you've already chosen is never changed, and Linux and the Pi are as they were.

Everything else is as in [0.16.1](https://github.com/simozzer/MzDebirth/releases/tag/v0.16.1).
