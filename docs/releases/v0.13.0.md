A sixth machine: the Mz7, a DX7. And patterns that copy between machines.

## Downloads

- **MzDebirth-0.13.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's twelve sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.13.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.13.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.13.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.13.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.
- **mzdebirth_0.13.0_arm64.deb** - Raspberry Pi 5 (beta), on 64-bit Raspberry Pi OS Bookworm or
  later: installs MzDebirth in the menu, under Sound & Video.
- **MzDebirth-0.13.0-linux-arm64-beta.tar.gz** - the same for any 64-bit ARM distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.13.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

**Raspberry Pi 5:** install the arm64 .deb the same way,

    sudo apt install ./mzdebirth_0.13.0_arm64.deb

and choose the "default" or "pipewire" output under Options. A Pi is much slower than a
desktop PC, so if the sound crackles, raise the buffer size there. This is the least tried
build of all: it's built natively on GitHub's ARM machines and passes the same checks as the
others, but hasn't yet been run on a Pi. A Pi 4 on 64-bit Raspberry Pi OS may run it too, if
more slowly; a 32-bit system won't.

## What's new

- **The Mz7.** A DX7 joins the rack, under the Mz950, from the new
  [Mz7](https://github.com/simozzer/Mz7) plugin.
  - **Voices:** pick a cartridge - four come with it, 128 voices of electric pianos, basses,
    brass, bells, pads and effects - or **LOAD .SYX** for any DX7 cartridge. Then pick a
    voice.
  - **Knobs:** **BRIGHT**, **ATTACK**, **DECAY** and **RELEASE** move the whole voice at once,
    and **MOD** is its mod wheel. They're all automatable in a song.
  - **Patterns:** its steps are a grid of notes like the Mz950's, with chords, accents and
    ties.
  - **GENERATE** writes it chords in the key: stabs in most styles, a pad in Deep and in the
    breakdown. **TRANSPOSE** moves them with everything else.
  - **The demo song** has a Keys track for it: electric piano stabs through the drops and
    chords under the breakdown.
- **Copy and paste between machines.** A copied pattern now pastes onto another machine where
  it fits:
  - a mono synth's line onto the other mono synth, at the same pitches;
  - a mono synth's line onto the Mz950 or the Mz7, as notes;
  - the Mz950's and the Mz7's notes onto each other.

  A drum pattern still pastes only onto its own machine, and chords don't paste onto a mono
  synth - PASTE dims there.

Racks saved before open as they were, with the Mz7's patterns empty until you write or
generate some. Everything else is as in [0.12.1](https://github.com/simozzer/MzDebirth/releases/tag/v0.12.1).
