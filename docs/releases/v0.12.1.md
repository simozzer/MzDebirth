MzDebirth for the Raspberry Pi 5, as a beta.

## Downloads

- **MzDebirth-0.12.1-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's twelve sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.12.1-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.12.1-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.12.1_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.12.1-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.
- **mzdebirth_0.12.1_arm64.deb** - Raspberry Pi 5 (beta), on 64-bit Raspberry Pi OS Bookworm or
  later: installs MzDebirth in the menu, under Sound & Video.
- **MzDebirth-0.12.1-linux-arm64-beta.tar.gz** - the same for any 64-bit ARM distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.12.1_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

**Raspberry Pi 5:** install the arm64 .deb the same way,

    sudo apt install ./mzdebirth_0.12.1_arm64.deb

and choose the "default" or "pipewire" output under Options. A Pi is much slower than a
desktop PC, so if the sound crackles, raise the buffer size there. This is the least tried
build of all: it's built natively on GitHub's ARM machines and passes the same checks as the
others, but hasn't yet been run on a Pi. A Pi 4 on 64-bit Raspberry Pi OS may run it too, if
more slowly; a 32-bit system won't.
