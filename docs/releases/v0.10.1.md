MzDebirth for Linux, as a beta, and an icon of its own.

## Downloads

- **MzDebirth-0.10.1-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's seven sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.10.1-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.10.1-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.10.1_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.10.1-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.10.1_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

## What's new

- **Linux (beta).** Built on Ubuntu 22.04, so it runs there and on everything since, and
  passes the same checks as the Windows version. It also runs under **WSL** on Windows 11:
  WSL has no sound card, so the .deb sets ALSA up to play through WSL's sound server - only
  under WSL - and `READ ME FIRST.txt` says how by hand. Not yet tried much on real Linux
  desktops, so reports are welcome on the
  [issue tracker](https://github.com/simozzer/MzDebirth/issues).
- **An icon:** a knob and four step pads, on the Windows app and its shortcuts, the Mac app,
  and the Linux menu.

Everything else is as in [0.10.0](https://github.com/simozzer/MzDebirth/releases/tag/v0.10.0).
