Woodwind, brass and strings for the Mz950, and a kick with weight.

## Downloads

- **MzDebirth-0.12.0-win64-Setup.exe** - Windows: the installer. The app, a Start menu entry,
  an uninstaller, and the Mz950's twelve sample disks. Per-user installs need no admin rights.
- **MzDebirth-0.12.0-win64.zip** - Windows: the same, to run without installing. Keep the
  `disks` folder beside `MzDebirth.exe`.
- **MzDebirth-0.12.0-macOS-beta.zip** - macOS (beta): the app and the Mz950's disks, with an
  install script.
- **mzdebirth_0.12.0_amd64.deb** - Linux (beta), for Ubuntu 22.04 and later, Debian, Mint and
  the like: installs MzDebirth in the applications menu.
- **MzDebirth-0.12.0-linux-x86_64-beta.tar.gz** - Linux (beta), any 64-bit x86 distribution:
  unpack and run, nothing installed.

**Windows:** Windows 10 or 11, 64-bit. The app is not code-signed, so Windows may warn about
an unknown publisher: choose **More info**, then **Run anyway**.

**macOS:** Apple Silicon and Intel Macs, macOS 11 or later. The download isn't signed by
Apple, which takes a paid developer account, so macOS won't open it with a double-click.
Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped
folder into the window, and press Return. It puts the app in Applications and the disks in
`~/Library/Application Support/MzDebirth`, and clears the quarantine flag. `READ ME FIRST.txt`
in the zip explains how to install by hand instead.

**Linux:** with the .deb,

    sudo apt install ./mzdebirth_0.12.0_amd64.deb

then open MzDebirth from the applications menu, or run `mzdebirth`; `apt` fetches what it
needs, and `sudo apt remove mzdebirth` takes it away again. With the .tar.gz, unpack it
anywhere and run `./MzDebirth` in it, keeping the `disks` folder beside it; `READ ME
FIRST.txt` in it lists the few libraries a minimal system might lack. It plays through ALSA,
which PipeWire and PulseAudio both provide.

## What's new

- **Woodwind, brass and strings.** The Mz950 comes with four more disks, twelve in all:
  `WOODWIND` (flute, piccolo, recorder), `BRASS` (trumpet, trombone, tuba, French horn and a
  brass section), `STRINGS` (solo violin, viola and contrabass, bowed and pizzicato) and
  `ENSEMBLE` (the same as sections of four to eight players). **LOAD DISK** on the Mz950,
  then pick a programme. Like the rest of the library they are drawn rather than recorded,
  and the sustained ones loop seamlessly. The other eight disks are unchanged.
- **A fresh start on every disk.** Loading a disk puts the Mz950's knobs back where they
  start, all but GAIN, so a filter or envelope setting made for the last disk no longer
  carries onto the next.
- **A kick with weight.** The factory mix is about 10 dB louder and far less spiky: the
  Mz808 goes through a soft DIST as well as the COMP, the faders come up, and MASTER goes to
  1.0 into the limiter. The Mz909's fader comes up to match, so its kick is as heavy as the
  808's.
- **A tutorial.** [docs/tutorial.md](https://github.com/simozzer/MzDebirth/blob/main/docs/tutorial.md)
  is the first half hour, from the demo song to a song of your own, and the README has a
  Troubleshooting section for the questions that come up most.

Everything else is as in [0.11.0](https://github.com/simozzer/MzDebirth/releases/tag/v0.11.0).
