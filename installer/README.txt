MzDebirth @VERSION@ - a rack of the Mz synths on one step sequencer, for Windows (64-bit)
https://github.com/simozzer/MzDebirth

The easiest way to install is MzDebirth-@VERSION@-win64-Setup.exe from the releases
page, which adds a Start menu entry and an uninstaller. This zip is for running it as
it is.

Run MzDebirth.exe. Options (top left) chooses the audio device; PLAY, or the space bar,
starts the rack. Keep the disks folder beside it: the Mz950 opens its drums from there.

Windows may warn that the app is from an unknown publisher: it is not code-signed.
Choose "More info" then "Run anyway", or build from source.
